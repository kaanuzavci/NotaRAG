# Yazı tipleri

Arayüzün yazı tipleri yerelden sunulur (`.streamlit/config.toml` → `[[theme.fontFaces]]`, `server.enableStaticServing`),
böylece internetsiz sunumda da aynı görünür. Yalnızca Türkçe için gereken alt kümeler var: latin + latin-ext.

- Instrument Sans (400, 500, 600), Fraunces (500, 600, 700), JetBrains Mono (400, 500)
- Kaynak: Google Fonts, 2026-10-06. Lisans: SIL Open Font License 1.1 (üçü de); yeniden dağıtıma izin verir.
- `fontlar.json`: dosya → aile, kalınlık, unicode aralığı.
